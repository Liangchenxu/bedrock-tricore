## 3. 真实问题与根因排查

### 3.1 ASCII 数据流框在 PyPI/浏览器错位

原框图依赖字符等宽，但图中含 Greek、Unicode 上下标与中英文；不同字体下字符宽度不一致，导致边框在 PyPI 或浏览器被截断/错位。根因是“字符数布局”无法跨字体保持视觉对齐。

### 3.2 `TriCoreLM` 没有 `_resolve_masks`

架构师提供的 telemetry 片段调用 `_resolve_masks`，但实际类只有 `_build_masks(idx)`，返回 `((elig_sep_mask, write_sep_mask), reset_mask)`。直接照搬会 `AttributeError`。

### 3.3 Telemetry 门控与实际 forward 不一致

如果 telemetry 只算 `write_gate_proj` / `elig_gate_proj`，会漏掉 `gate_token_proj` 的短路径和 `gate_role_table` 的角色 logits，导致探针数值与真实 forward 的门控不一致。

## 4. 解决方案

- 用 matplotlib + `FancyBboxPatch` / `FancyArrowPatch` 绘制矢量级蓝图；README 两个语言部分引用同一 URL，避免双份漂移。
- `inspect_telemetry` 改用 `_build_masks(idx)`；显式加入 token gate 与 role gate，再应用 `separator_mask` 的 8.0 logit 抑制，与实际 `forward` 对齐。
- 先 push 蓝图与 README，再构建/上传，保证 Raw URL 在 PyPI 抓取时已 200。
- 测试覆盖 `generate()` 输出形状、prompt+6 Token 的 surprise 长度、17,408 B 状态、telemetry 键/形状/有限值。
