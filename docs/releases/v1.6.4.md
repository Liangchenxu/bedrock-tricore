# Bedrock-TriCore v1.6.4

**Release date:** 2026-10-28  
**PyPI:** https://pypi.org/project/bedrock-tricore/1.6.4/  
**Version vault:** https://github.com/Liangchenxu/bedrock-tricore/blob/main/docs/versions/INDEX.md

v1.6.4 is a consolidated infrastructure release. It includes the accumulated packaging, equation-rendering, architecture-blueprint, telemetry, and chunked-state work since v1.6.0. The intermediate v1.6.1–v1.6.3 GitHub Releases were not published separately; this release is the single consolidated entry for that line.

## Highlights

- **Stateful chunked prefill** — `TriCoreLM.forward_chunked(idx, chunk_size=256, states=None, return_states=False)` bounds peak activations while carrying `(h, F_mat, prev_k)` across chunks.
- **17 KiB state snapshots** — `save_state_snapshot()` / `load_state_snapshot()` serialize FP32 **17,408 B/sample** or BF16 **8,704 B/sample** state with architecture metadata and SHA-256 integrity checking.
- **Chunk-boundary correctness** — a carried state at local `t=0` performs the normal Delta/Hebbian write and reset; only a true sequence start skips the first write.
- **Chunked `generate()` prefill** — prompt prefill now uses `forward_chunked(..., chunk_size=256, return_states=True)`.
- **Official CLI** — `bedrock-tricore info`, `bedrock-tricore verify`, and `bedrock-tricore benchmark`; `python -m tricore` is equivalent.
- **Version vault** — `docs/versions/` records v1.6.0–v1.6.4 engineering retrospectives and preserves the V4–V13 historical archive.

## New API

```python
from tricore import TriCoreLM

model = TriCoreLM(
    vocab_size=64, d_model=128, n_layers=1, d_fast=32, max_loops=2
).eval()

chunk_logits, chunk_surprise, chunk_states = model.forward_chunked(
    prompt, chunk_size=64, return_states=True
)

snapshot = model.save_state_snapshot(
    chunk_states, path="tricore_state.pt", compress_bf16=True
)
restored = model.load_state_snapshot("tricore_state.pt")
```

Snapshot fields: `format`, `version`, `arch`, `dtype`, `compress_bf16`, `state_bytes`, `state_bytes_per_sample`, `layers`, `sha256`.
